Yeeps Note Extractor

MusicXML → Yeeps Paint + Note Block & Delay Block list. No server upload (local browser client-only processing).

Limitations (read before converting)
  • Sixteenth-note grid only — timing snaps to sixteenths. 32nds, 64ths, and anything faster than a sixteenth won't place correctly.
  • No tuplets — triplets, quintuplets, etc. don't map cleanly onto Yeeps wire/delay timing; simplify the score first.
  • Grace notes are skipped — they are ignored and do not produce note blocks.
  • Tied notes — only the start of a tie is an onset; continuations are not repeated (intended for Yeeps).
  • Simple scores — score-partwise MusicXML from MuseScore-style exports. No repeat/ending expansion, no timewise scores.
  • Pitch range — only pitches covered by Yeeps paints map; others show as No Paint.
  • Tempo — Yeeps patterns are keyed by quarter-note BPM (♩ = 300...33). Metronome markings in other units (e.g. ♪ = 120) are converted to ♩ before snapping.
  • No mid-score tempo changes — only the first tempo marking is used; the whole piece gets one Yeeps space pattern. Later ritardandi / new metronome marks are ignored.
